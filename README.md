# FINAL PROJECT SOFTWARE TESTING
Software Testing Lab Project for Python Pickle Module Stability and Correctness Testing using Black-Box Testing, Boundary Value Analysis, Fuzz Testing, and White-Box Testing.

## Running All Tests
```bash
python run_all_tests.py
```

## Individual Test Files
- black_box_pickle_test.py - Equivalence partitioning tests
- boundary_pickle_test.py - Boundary value analysis tests
- fuzz_test.py - Fuzz testing with random inputs
- white_box_test.py - White-box testing (control flow, data flow, coverage)
- unstable_test.py - Tests for unstable pickle behavior scenarios
